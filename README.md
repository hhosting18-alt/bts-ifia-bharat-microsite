# BTS × IFIA Bharat Microsite — v13

This build includes the four-page React/TypeScript microsite plus the latest Awards-page visual fixes:
- removed the Awards Ceremony decorative star/confetti pseudo-element that was overlapping the ceremony text;
- removed the unwanted white top-line artefact from the transparent Awards CTA globe asset;
